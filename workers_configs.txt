1. Request to /admin/stats
2. WAF Rule 1: /api/ bypass → NO (not /api/)
3. WAF Rule 2: IN traffic → NO (if not from India)
4. WAF Rule 3: ASN block → NO (if not blocked ASN)
5. WAF Rule 4: Bad bot → NO (if not bot)
6. WAF Rule 5: AI bot → NO (if not AI bot)
7. REACHES WORKER
8. Worker checks X-Admin-Token
9. If valid → returns admin data
10. If invalid → returns 403
